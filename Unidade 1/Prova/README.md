# Prova Unidade 1

Resoluções da Prova da Unidade 1 - Introdução à Programação.

Cada questão está em um arquivo separado (`questao_01.py`, `questao_02.py`, ...). Cada arquivo traz o enunciado como comentário e, logo abaixo, a resolução em Python.

Total: **11 questões**.

## Observações úteis

- As questões 1 a 8 são de múltipla escolha.
- As questões de 9 a 11 são de implementação de código.

## Como executar

```bash
python questao_xx.py    # onde xx é o número da questão
```

Digite os dados pedidos quando o programa solicitar.

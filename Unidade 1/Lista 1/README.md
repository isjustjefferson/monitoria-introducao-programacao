Total: **5 questões**.

## Observações úteis

- `input()` sempre lê um TEXTO (string).
- `int(input())` converte para número inteiro.
- `float(input())` converte para número decimal.
- `print()` mostra o resultado na tela.

## Como executar

```bash
python questao_01.py
```

Digite os dados pedidos quando o programa solicitar.

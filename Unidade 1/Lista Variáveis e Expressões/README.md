# Lista de Variáveis e Expressões

Resoluções da lista de exercícios de Variáveis e Expressões - Introdução à Programação.

Cada questão está em um arquivo separado (`questao_01.py`, `questao_02.py`, ...). Cada arquivo traz o enunciado como comentário e, logo abaixo, a resolução em Python.

Total: **52 questões**.

## Observações úteis

- `int(input(...))` lê um número inteiro.
- `float(input(...))` lê um número decimal.
- `input(...)` lê um texto (string).
- `print(...)` mostra o resultado na tela.
- `**` é potência (ex.: `5 ** 2 = 25`).

## Como executar

```bash
python questao_01.py
```

Digite os dados pedidos quando o programa solicitar.

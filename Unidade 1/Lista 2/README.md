## Observações úteis

- Estrutura condicional: `if` / `elif` / `else`.
- `if`: SE a condição for verdadeira.
- `elif`: SENÃO SE (outra condição).
- `else`: SENÃO (nenhuma condição anterior foi verdadeira).

## Como executar

```bash
python questao_01.py
```

Digite os dados pedidos quando o programa solicitar.

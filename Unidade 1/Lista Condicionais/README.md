# Lista de Comandos Condicionais

Resoluções da lista de exercícios de Comandos Condicionais - Introdução à Programação.

Cada questão está em um arquivo separado (`questao_01.py`, `questao_02.py`, ...). Cada arquivo traz o enunciado como comentário e, logo abaixo, a resolução em Python.

Total: **41 questões**.

## Observações úteis

- Estrutura condicional: `if` / `elif` / `else`.
- Python não possui `switch/case`; usamos `if` / `elif` / `else`.
- Operadores relacionais: `==`, `!=`, `>`, `<`, `>=`, `<=`.
- Operadores lógicos: `and`, `or`, `not`.
- A raiz quadrada pode ser calculada com `** 0.5`; já o logaritmo exige a biblioteca `math` (`import math` e `math.log`).

## Como executar

```bash
python questao_01.py
```

Digite os dados pedidos quando o programa solicitar.
